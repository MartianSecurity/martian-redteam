# Scan fixture

A small repository for `martian scan` and the scan action's smoke test: a skill folder, an MCP
configuration and an instructions file, which the default agent paths send, and `src/app.py`,
which they do not. Nothing here is harmful; the CI smoke test's stand-in server reports one
seeded finding on `skills/release-notes/SKILL.md` so the gate can be seen failing.
