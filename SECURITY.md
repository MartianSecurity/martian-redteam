# Security policy

## Report a vulnerability

Report a vulnerability in the Martian SDK privately, through GitHub's private vulnerability
reporting: open this repository's **Security** tab and choose **Report a vulnerability**. Do not
open a public issue or pull request for it.

Include the SDK version (`martian --version`), the steps that reproduce the problem, and what an
attacker could do with it. Do not send credentials, customer data or real provider keys.

## Supported versions

Security fixes ship as a new release of `martian-sdk` on PyPI. Use the latest release.
